# RC3 — проверка и доставка, 2026-10-08

Ветка `4erk/capslang-1.1.0`, кандидат `1.1.0-rc.3`. Новая функция — исправление
раскладки выделенного текста Ctrl+CapsLock. Скачивание остаётся одним EXE;
встроенные x64/x86 модули распаковываются по хешу в защищённую папку.

## Подтверждено до финальной сборки

- Пользователь подтвердил преобразование в Opera на ноутбуке.
- Уточнено правило: направление из выделения, не текущей раскладки;
  смешанный текст меняется в обе стороны, без смены общего языка.
- Повторная ручная проверка этого правила в Opera: «работает».
- Обе машины временно получили одинаковый диагностический EXE
  `E9D554CA4F5374398E346BE2641394C5DC622BFB9FFCA2E01EB0825D2D6F3A9B`.
  Пользователь подтвердил проверку Ctrl+CapsLock на ПК через MWB, со сменой
  языка обоих устройств после замены: «работает».
- Координаторы NB 12720 и PC 13404 завершились кодом 0; прежний установленный
  EXE и зашифрованные файлы пары сохранены, задачи/служба восстановлены,
  временные задачи и правила удалены. Временное правило передачи файлов также
  удалено. Эти результаты не являются постоянной установкой RC3.
- До смены версии: core 515, SYSTEM protocol 131120, profile channel 62,
  Windows integration 237, application 348 и остальные RuntimeTestsOnly — зелёные.

## Доставка

Готовится финальная Release-сборка без диагностического режима, с повторением
тестов и второй чистой сборкой для сравнения SHA-256. Установка обоих устройств
использует штатную административную транзакцию и обычный координатор миграции;
сопряжение не пересоздаётся. Проверки доставки фиксируются ниже по результатам.

Не завершённые проверки стабильного выпуска перечислены в [состоянии 1.1](1.1-status.md).
RC3 публикуется как prerelease. Непроверенная длительная приёмка не выдаётся
за выполненную физическую работу.
