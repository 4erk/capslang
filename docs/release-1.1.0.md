# CapsLang 1.1.0

CapsLock переключает EN/RU на двух Windows x64 устройствах, Shift+CapsLock
работает как обычный Caps Lock, Ctrl+CapsLock исправляет выделенный текст.

SHA-256 CapsLang.exe:
`793b07e03995594397a76d1f2442025eb4579b5d211ebfe35f993bf4d1da23e3`.
Две чистые Release-сборки совпали побайтно. Полный набор автоматических тестов
прошёл; соответствие 95 печатных ASCII-клавиш проверено через установленные
раскладки Windows, без отправки клавиатурного ввода.

## Новое после RC3

Преобразуются не только буквы, но все различающиеся печатные символы основных
клавиш English US / Russian, включая Shift+цифры и пунктуацию:

- `ghbdtn@` → `привет"`.
- EN→RU `@#$^&|/` → `"№;:?/.`; RU→EN — обратно.
- `ghbdtn@ привет"` → `привет" ghbdtn@`, без смены общего языка.

Знаки рядом со словом используют направление этого слова. В отдельном блоке
знаков без букв направление задаёт текущая общая раскладка. Обычные цифры,
одинаковые знаки, пробелы и несопоставленный Unicode не изменяются. Пустое
выделение и одни неизменяемые цифры общий язык не переключают. Произвольная
пунктуация смешанного текста неоднозначна; универсальная обратимость не обещается.

Замена сохраняет выделение, не использует буфер обмена и не отправляет текст
по сети. После успешной одноязычной замены передаётся только язык результата.

## Установка

Сверьте EXE с SHA256SUMS.txt. Запустите `CapsLang.exe --install` обычным
пользователем и подтвердите UAC. Обновите оба устройства до одной версии.
Сопряжение сохраняется, предыдущая сборка доступна через `--rollback`.
Фоновые процессы без консоли и трея; постоянных запросов UAC нет.

## Проверки и известные ограничения

По прямому запросу пользователя релиз выпускается без двухчасового физического
прогона. Это не утверждение о прохождении 100 переходов или полной матрицы
редакторов, сна и блокировки. Короткие проверки и автоматические тесты остаются.

- Требуется EDIT или совместимый TSF-редактор. Пароли, read-only и неизвестные
  сведения о защищённости поля отклоняются без clipboard fallback.
- EDIT: всё поле до 65536 символов; TSF: выделение до 65536 UTF-16 единиц.
  Дождитесь завершения замены перед повторным Ctrl+CapsLock.
- В EDIT проверяется фактический результат замены и ограничение поля. При
  усечении/отказе восстанавливается исходный текст; неудача не меняет общий язык.
  Восстановление может сбросить историю Undo, если само Undo отказано редактором.
- Отдельный владелец hook для 32-битных приложений и автоматическая миграция
  сохранённого IP на имя компьютера ещё не реализованы.
- В установщике ранее наблюдалась временная ошибка готовности обработчика
  (код 2), требовавшая контролируемого повтора после отката. После отказа
  проверяйте прежнюю версию и состояние процессов; автоматическое исправление
  этой гонки не заявляется.
- Экран UAC/входа, драйверы, автообновление и вложенный RDP-сеанс вне выпуска.
  EXE не подписан: не отключайте защиту Windows, проверяйте хеш.
- Старый отдельный Screensaver Guard на существующих установках пока сохраняется.
  PowerToys remap, AutoHotkey, VPN, сон, экран и блокировка не перенастраиваются.
