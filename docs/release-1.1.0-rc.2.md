# CapsLang 1.1.0-rc.2

Предварительный выпуск. Стабильная 1.1.0 требует завершённой двухмашинной
приёмки, двухчасового прогона и 100 физических переходов через MWB.

## Изменения

- Один локальный SYSTEM-обработчик CapsLock получает клавишу в системном окне
  MWB до первого клика; обычное ядро больше не создаёт второе переключение.
- Защищённый канал передаёт только команды переключения, с последовательными
  номерами и подтверждениями. Текст и обычные клавиши не читаются и не передаются.
- Исправлена проверка идентичности SYSTEM-процесса при запуске из планировщика;
  работа не зависит от дополнительных прав RDC.
- Смена языка наблюдается внутри рабочего потока окна. Собственные применения,
  ручной выбор и смена фокуса разделены, результат привязан к поколению запроса.
- Фоновое ядро не использует синтетические Win+Space, F24 или Scroll Lock.
- Защита от заставки работает внутри обычного фонового процесса; отдельный
  минимальный watchdog восстанавливает состояние после его аварийного завершения.
- Откат относится к предыдущей установленной сборке. Исторические EXE сохраняются.

## Установка и обновление

Проверьте SHA-256 по `SHA256SUMS.txt`, запустите CapsLang.exe и выберите установку.
Для обновления — `CapsLang.exe --install`. Установка требует одного UAC;
обычный вход в Windows не требует подтверждения. Сопряжение и сертификаты
сохраняются при обновлении. На обоих устройствах нужна одинаковая версия.

Для новой пары откройте установленный EXE на слушающем ПК, создайте приглашение,
вставьте его на ноутбуке, сверяйте отпечаток и подтвердите подключение на ПК.
Имя компьютера предпочтительнее меняющегося LAN-адреса. Не публикуйте приглашение.

## Ограничения

- Windows x64, два устройства, English US / Russian, обычный интерактивный desktop.
- Экран UAC и входа, драйверы, цифровая подпись и автообновление не поддерживаются.
- Windows может показывать предупреждение о неизвестном издателе: EXE не подписан.
- Для наблюдателя 32-битных приложений ещё не реализован отдельный владелец hook.
- Автоматическое преобразование ранее сохранённого IP в имя компьютера пока не выполнено.
- Зелёные автоматические тесты не заменяют физическую проверку индикаторов и печати.
- Стабильный выпуск не объявляется до прохождения полного приёмочного списка.

PowerToys remap, AutoHotkey, VPN, раскладки, сон, гашение экрана и блокировка
не перенастраиваются. Подавляется только заставка во время локального MWB.
