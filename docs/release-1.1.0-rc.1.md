# CapsLang 1.1.0-rc.1

Первый предварительный выпуск полной двухпроцессной версии: локальное
переключение EN/RU, повышенные пользовательские окна, защищённая синхронизация
двух компьютеров через LAN при работающем Mouse Without Borders.

## Изменения относительно 1.0.0

- Вместо синтетического Win+Space — точный EN/RU через Windows API с проверкой
  фактической раскладки. Удержание CapsLock не повторяет переключение;
  Shift+CapsLock сохраняет обычный Caps Lock.
- Повышенный локальный обработчик без сети; обычный интерфейс/сетевой процесс.
  Установка в Program Files с одноразовым UAC, две задачи входа без пароля.
- Приглашение на пять минут, подтверждение отпечатка второго устройства,
  взаимный Schannel TLS и закреплённые сертификаты. Никаких ключей MWB,
  ввода текста или буфера обмена в протоколе.
- Ручная смена языка и CapsLock обновляют общий EN/RU. Повторные/устаревшие
  сообщения не переключают язык второй раз. После обрыва учитывается последний
  получатель ввода, а не часы системы или постоянный приоритет ПК.
- Рабочее окно за служебной точкой MWB поддерживается в общем языке без клика.
- После согласования каждое новое изменение применяется на обоих устройствах,
  даже пока мышь остаётся на одном; получение раскладки не ждёт локального ввода.
- Обратный порядок задач входа не приводит к отказу: обычный процесс запускает
  обработчик и ожидает готовности без повторного UAC.
- Нет F24-проб, синтетического Scroll Lock и ожиданий в hook callback.
- Аппаратный LED с явным сообщением о неподдерживаемых устройствах.
- Защита от заставки во время MWB без изменения сна/экрана/блокировки.
- Транзакционный установщик, резервная копия, откат 1.0.0 отдельно от утилиты
  2015 года, JSON-статус, экспорт диагностики и ротируемый технический журнал.

## Установка и сопряжение

1. Проверьте SHA-256 CapsLang.exe по приложенному SHA256SUMS.txt.
2. Запустите EXE обычным двойным кликом на обоих ПК и выберите «Установить».
   При обновлении используйте `CapsLang.exe --install`.
3. Откройте установленный EXE на ПК, укажите имя компьютера или его LAN IP,
   нажмите «Создать код». На ноутбуке вставьте приглашение и подключитесь.
4. Сверьте отпечаток ноутбука с запросом на ПК и подтвердите пару на ПК.

Правило брандмауэра: только этот EXE, TCP 42519, LocalSubnet, все профили.
Категория сети, VPN, PowerToys remap и настройки раскладок не изменяются.
Приглашение не публикуйте. Нестабильный IP лучше заменить разрешаемым LAN-именем.

## Ограничения RC

- Windows x64, два устройства, EN-US/RU. Поддерживаемая версия MWB:
  PowerToys 0.101.2362.0, абсолютное перемещение, HideMouseAtScreenEdge=true,
  BlockScreenSaverOnOtherMachines=false. Встроенная защита CapsLang заменяет
  только функцию подавления заставки. Настройки MWB не изменяются молча.
- Нет поддержки UAC secure desktop, экрана входа и SYSTEM-окон. Драйверы,
  цифровая подпись и автообновление не входят в выпуск.
- EXE не подписан; Windows может показать предупреждение об издателе.
- Не каждая клавиатура позволяет управлять LED через IOCTL. Неподдерживаемые
  устройства отражаются в статусе; синтетических нажатий вместо IOCTL нет.
- RC не является завершённой двухмашинной приёмкой: сон/блокировка, все
  пользовательские приложения, двухчасовой прогон и 100 реальных переходов
  ещё должны быть подтверждены перед стабильной 1.1.0.

Резервные EXE и прежняя отключённая утилита сохраняются, в том числе при удалении.
Подробные результаты и границы: [журнал проверок](https://github.com/4erk/capslang/blob/4erk/capslang-1.1.0/docs/1.1-status.md).
