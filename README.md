# CapsLang

Переключение English (US) ↔ Русский клавишей CapsLock и общая раскладка двух
Windows x64 компьютеров с PowerToys Mouse Without Borders (MWB).

- CapsLock переключает один раз; удержание не повторяет переключение.
- Shift+CapsLock оставляет обычный Caps Lock.
- Ctrl+CapsLock исправляет раскладку выделенного текста EN↔RU, независимо от
  текущего языка клавиатуры; выделение и регистр сохраняются.
- Повышенный локальный обработчик поддерживает административные окна;
  обычный процесс обслуживает интерфейс и защищённое соединение.
- Раскладка передаётся как EN/RU, без ввода Win+Space или служебных клавиш.
- Индикатор Scroll Lock не используется; ориентир — штатный индикатор Windows.
- Во время MWB отключается только заставка, без перенастройки сна, экрана и блокировки.
- В фоне нет консоли и значка в трее. Текст ввода не записывается и не передаётся.

## Скачать и установить

[Предварительный выпуск 1.1.0-rc.3](https://github.com/4erk/capslang/releases/tag/v1.1.0-rc.3)
содержит CapsLang.exe, контрольную сумму и список ограничений.
Стабильная 1.0.0 не имеет синхронизации и поддержки повышенных окон.

Запустите EXE обычным двойным кликом, выберите «Установить». Один запрос UAC
разрешает установку в `%ProgramFiles%\CapsLang` и две задачи входа текущего
пользователя: локальный обработчик с повышенными правами и обычный сетевой
процесс, а также локальную SYSTEM-службу для CapsLock и системных окон MWB.
Служба не имеет сетевых функций. Пароль не сохраняется. При обычном входе UAC
не нужен. Для обновления существующей установки используйте `--install`.

Установщик сохраняет прежний EXE и определения собственных задач, проверяет
новый запуск и только после этого отключает автозапуск 1.0.0. Неудачная
административная транзакция восстанавливает предыдущую установку. Резервные
файлы не удаляются. Старый capslang-win-space.exe.disabled сохраняется.

EXE не подписан. Windows может показать «Неизвестный издатель» / SmartScreen;
это ожидаемо, но само по себе не подтверждает безопасность файла. Проверяйте
SHA-256 из выпуска. Не отключайте защиту Windows.

## Сопряжение

На обоих устройствах установите эту версию. Откройте установленный EXE:

1. На ПК укажите его имя в локальной сети или LAN IP, создайте приглашение.
2. На ноутбуке вставьте код и нажмите «Подключиться».
3. Сверьте отпечаток ноутбука с запросом на ПК и подтвердите пару на ПК.

Приглашение действует пять минут. После подтверждения используется взаимный
Schannel TLS с закреплёнными сертификатами; корневые сертификаты не добавляются.
Код не публикуйте. Ключ MWB, память MWB и буфер обмена как транспорт не используются.
ПК слушает TCP 42519. Правило брандмауэра ограничено этим EXE, портом и
LocalSubnet, включая Public; параметры VPN не меняются. Если адрес нестабилен,
используйте разрешаемое имя компьютера.

Общий язык изменяют CapsLock, ручное переключение Windows и успешная
одноязычная замена Ctrl+CapsLock. Фокус другого окна сам по себе не меняет
общий язык. После обрыва сопоставляются явные изменения относительно последнего
общего состояния; при неопределённом порядке ожидается новый явный выбор языка.
Без соединения локальный CapsLock продолжает работать.

## Исправить раскладку текста

Выделите ошибочно набранный текст и нажмите Ctrl+CapsLock: `ghbdtn` → `привет`,
`руддщ` → `hello`. После успешной одноязычной замены оба компьютера получают
язык результата. В смешанном выделении `ghbdtn привет` → `привет ghbdtn`,
общий язык не меняется. Без выделения ничего не происходит.

Текст остаётся выделенным; повторное нажатие преобразует его обратно.
Неоднозначная пунктуация смешанного текста не гарантирует универсального
обратного преобразования. Это соответствие клавиш, не перевод и не транслитерация.
Буфер обмена не используется. Текст не журналируется и не передаётся по сети.
Нужен редактируемый EDIT или совместимый TSF-редактор; парольные, read-only и
поля с неизвестными сведениями защиты отклоняются без запасного copy/paste.
Подробные ограничения: [примечания к RC3](docs/release-1.1.0-rc.3.md).

## Команды

| Команда | Действие |
|---|---|
| `--install` | Установить / обновить (UAC) |
| `--background` | Скрытый запуск установленной версии |
| `--run-once` | Ограниченный запуск без установки и повышенных окон |
| `--status`, `--pair` | Окно состояния и сопряжения |
| `--status --json` | Технический статус без секретов |
| `--restart` | Перезапустить установленный обработчик и соединение |
| `--diagnose` | Экспортировать технический статус |
| `--uninstall` | Отключить новую установку, оставить резервные файлы |
| `--rollback` | Вернуть предыдущую установленную сборку |

Журнал: `%LOCALAPPDATA%\CapsLang\capslang.log`, ротация 1 МиБ + предыдущий файл.
Диагностика не включает текст, заголовки окон, приглашения и ключи.

## Границы предварительного выпуска

- Две машины, English US / Russian, интерактивный Windows desktop.
- Синхронизация включается при запуске MWB в пользовательском сеансе на обоих
  компьютерах и установленном защищённом соединении CapsLang. Она не использует
  канал MWB и не требует определения получателя мыши или точной версии PowerToys.
- UAC secure desktop, экран входа, драйверы, подпись и автообновление
  не входят в выпуск. Окно-точка MWB не является текстовым приложением: CapsLang
  обновляет последнее рабочее окно за ним без перевода фокуса.
- LED Scroll Lock исключён; используйте штатный индикатор Windows.
- Для наблюдения 32-битных приложений отдельный владелец hooks ещё не реализован.
- Сохранённый IP не мигрирует автоматически в имя компьютера. Сопряжение при
  обновлении сохраняется; для новой пары предпочтительно разрешаемое имя.
- Защита от заставки встроена в фоновый процесс. На существующих установках
  старый Guard сохраняется до проверенной передачи ответственности.
- RC не означает завершённой двухчасовой приёмки, 100 переходов, сна/блокировки
  и всех пользовательских приложений. [Журнал проверок](docs/1.1-status.md).

## Сборка и тесты

```powershell
.\build.ps1
```

Закреплён LLVM-MinGW **20260616/UCRT x64**, SHA-256 архива проверяется при
получении. Скрипт выполняет тесты ядра, IPC/TLS/синхронизации и приложения,
затем создаёт dist/CapsLang.exe и dist/SHA256SUMS.txt. Временная метка PE
выключена. Отдельных runtime-пакетов и сетевой загрузки при запуске EXE нет.

`-RuntimeTestsOnly` тестирует компоненты на неактивном desktop/loopback;
`-AppDevOnly` собирает приложение в build/app-dev; `-SkipTests` пропускает
тесты. Эти режимы ничего не устанавливают. `tests\run-elevated.ps1 -Engine`
проверяет повышенный обработчик на отдельном desktop, не заменяя живую приёмку.
