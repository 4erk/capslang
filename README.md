# CapsLang

Надёжная пользовательская утилита для Windows 10/11:

- `CapsLock` переключает English (US) ↔ Русский;
- `Shift+CapsLock` сохраняет обычное поведение Caps Lock;
- Scroll Lock LED выключен для English и включён для Русского;
- keyboard hook работает на отдельном потоке и автоматически восстанавливается;
- программа не записывает нажатия клавиш и не требует прав администратора.

## Скачать

Готовая x64-сборка: [CapsLang.exe](https://github.com/4erk/capslang/releases/latest/download/CapsLang.exe).

Windows покажет предупреждение SmartScreen, потому что первая версия пока не
подписана цифровым сертификатом. Исходный код и воспроизводимая сборка находятся
в этом репозитории.

## Сборка

```powershell
.\build.ps1
```

Скрипт скачивает закреплённый LLVM-MinGW 20260616 в
`%LOCALAPPDATA%\CapsLangBuildCache`, проверяет SHA-256, запускает тесты и создаёт
`dist\CapsLang.exe`. У готового EXE нет внешних runtime-зависимостей.

### Подготовка 1.1

В ветке разработки сначала проверяются Windows API и совместимость с MWB.
`./build.ps1 -ProbeOnly` собирает отдельный `build\probe\CapsLangProbe.exe`;
он **не является новой версией или release candidate** и не меняет автозапуск.
Порядок проверок: [проверка предпосылок](docs/1.1-feasibility.md).

## Установка

Запустите `dist\CapsLang.exe` двойным кликом и нажмите **Установить**. Программа:

1. сохранит себя как `%LOCALAPPDATA%\CapsLang\CapsLang.exe`;
2. добавит пользовательский автозапуск в `HKCU\...\Run`;
3. остановит старый `capslang-win-space.exe`;
4. сохранит его рядом под именем `capslang-win-space.exe.disabled`;
5. запустится в полностью скрытом режиме.

Повторный двойной клик по установленному EXE открывает окно состояния и команды
перезапуска, удаления и возврата старой версии.

## Командная строка

- `--background` — скрытый фоновый режим;
- `--install` — установить и включить автозапуск;
- `--run-once` — запустить без установки;
- `--status` — показать состояние запущенного экземпляра;
- `--restart` — перезапустить keyboard hook;
- `--uninstall` — удалить новую версию, оставив старую отключённой;
- `--restore-legacy` — удалить новую версию и вернуть старую.

Журнал самовосстановлений хранится в
`%LOCALAPPDATA%\CapsLang\capslang.log` и ротируется после 256 КиБ. Содержимое
вводимых данных и обычные нажатия клавиш в журнал не попадают.

## Ограничение

Программа намеренно устанавливается без UAC. Из-за UIPI синтетическое
переключение может не работать в окнах, запущенных с повышенными правами.
