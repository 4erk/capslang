# CapsLang 1.1.0 — доставка, 2026-10-08

По прямому запросу пользователя исправлено преобразование всех печатных
клавиш English US / Russian: пунктуации, Shift+цифр, включая `|` ↔ `/`.
Буквенное направление применяется к знакам того же блока текста; отдельный
блок без букв использует противоположный текущему язык. Смешанное выделение
не переключает общий язык, одни неизменяемые цифры — тоже.

Пользователь отдельно запросил релиз без длительной приёмки. Двухчасовой
физический прогон и 100 переходов не выполнялись и не объявляются пройденными.
Короткая физическая приёмка RC3 уже подтвердила Opera, Ctrl+CapsLock через MWB
на ПК и смену общего языка. Она не является новой физической проверкой каждого
знака финальной сборки. Дополнительные автоматические проверки покрывают знаки
в настоящем EDIT и все 95 печатных ASCII клавиш.

Известные ограничения: [release notes](release-1.1.0.md). Сборка, публикация
и постоянная установка фиксируются ниже только после подтверждения.

## Проверки финального кода

Полная чистая Release-сборка завершилась code=0: core 615, Windows integration
248, application 348; SYSTEM protocol 131120, profile channel 62, queue 37,
settings 96, recipient 90/18/21, sync 1113, reconnect 1032, broker model 321,
profile host 31, IPC 109, TLS 141, LAN 78, broker session 23, runtime 23 — зелёные.
Дополнительная IntegrationOnly завершилась code=0: 269 проверок, включая
сравнение всех 95 печатных ASCII-символов с установленными раскладками Windows
через VkKeyScanEx/ToUnicodeEx без изменения состояния клавиатуры.

Проверки EDIT выявили отказ вставки в ограниченном поле. Добавлена проверка
полученного текста, предварительная проверка лимита и восстановление исходного
содержимого при частичной вставке; отказ не публикует новый общий язык.
При отказе без изменения текста прежнее пользовательское Undo не вызывается.
Регрессия намеренно меняет лимит собственного тестового EDIT во время вставки
и проверяет возврат исходного текста даже при ограниченном Undo.

Финальный первый EXE: `793B07E03995594397A76D1F2442025EB4579B5D211EBFE35F993BF4D1DA23E3`.
Более ранняя сборка `598D9B97...` предшествует защите от отказа EDIT и не публикуется.

Вторая `build.ps1 -Clean -SkipTests` завершилась code=0. Две финальные сборки
совпали побайтно с указанным выше SHA-256; PE timestamp=0, Windows GUI,
версия 1.1.0 без prerelease-флага. Диагностический режим не включён.
