# История изменений

## В разработке — 1.1.0 (не опубликована и не установлена)

- Разделены локальный повышенный движок и сетевые компоненты; добавлены
  защищённый локальный IPC, абсолютная установка EN/RU с проверкой результата,
  Schannel TLS и сопряжение с подтверждением второй стороны.
- Добавлены фильтрация доставленного ввода MWB, проверка поддерживаемой версии
  и безопасной конфигурации, ограниченная очередь событий и срок годности
  наблюдений. Ни исходные клавиши, ни текст, ни координаты не передаются.
- Подключено получение активности из движка через IPC; задержка обмена
  учитывается интервалом давности, без сравнения часов компьютеров.
- Аппаратный LED и чтение метаданных MWB выполняются вне hook/потока раскладки;
  зависание этих операций не должно удерживать переключение или остановку.
- Отдельный Screensaver Guard сохраняет запрет только заставки во время MWB,
  без синтетических движений, изменения сна, гашения экрана или автолока.

Это проверяемые компоненты разработки, **не готовый выпуск 1.1**. Установщик,
единый интерфейс/жизненный цикл, полная двухмашинная приёмка и Release EXE
ещё не завершены. Состояние и границы проверок: [docs/1.1-status.md](docs/1.1-status.md).

## 1.0.0 — 2026-08-04

- Переключение English (US) ↔ Русский одиночным нажатием `CapsLock`.
- Обычный Caps Lock по `Shift+CapsLock` без смены языка.
- Индикация текущей раскладки светодиодом Scroll Lock.
- Быстрый keyboard hook на отдельном потоке и автоматическое восстановление
  после потери hook, сна, разблокировки и смены пользовательской сессии.
- Установка в профиль пользователя без UAC, скрытая фоновая работа и журнал
  только служебных событий.
- Сохранение прежней версии CapsLang в отключённом виде для безопасного отката.

### Ограничения

- EXE пока не подписан цифровым сертификатом, поэтому Windows SmartScreen может
  показать предупреждение.
- Из-за UIPI переключение не гарантируется в окнах, запущенных с повышенными
  правами.
