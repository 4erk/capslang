# История изменений

## В разработке — подготовка 1.1.0-rc.2

Этот раздел не означает опубликованный или установленный выпуск.

- Новый модуль получает уведомления о смене языка внутри рабочего потока окна;
  проверочная ветка движка применяет EN/RU через этот же защищённый канал.
- Разделены собственные запросы, внешние уведомления и смена фокуса;
  подтверждение привязано к поколению запроса и свежему чтению состояния окна.
- Добавлены модули x64/x86 внутри одного скачиваемого EXE и подготовка
  защищённых файлов по хешу до остановки старой установки. Загруженные DLL
  не перезаписываются; предыдущие модули сохраняются для отката.
- Добавлены проверки настоящего межпроцессного применения, остановки
  владельца, повторного подключения и немедленной внешней смены языка.
- Диагностика больше не называет профиль фонового процесса системным
  индикатором. Проверочные сборки помечены `1.1.0-dev.2`, а не старым RC1.

Новый путь ещё не включён в обычный установленный запуск: остаются интеграция
с SYSTEM-окнами и 32-битным владельцем hooks, проверка рабочих приложений,
установки/отката и полная двухмашинная приёмка. Стабильный выпуск не объявлен.

## 1.1.0-rc.1 — предварительный выпуск

- Транзакционная установка в Program Files: защищённые файлы, журнал
  восстановления, сохранение 1.0.0, проверка запуска до отключения старого Run.
- Две задачи текущего пользователя: повышенное локальное ядро без сети и
  обычный сетевой процесс. Повторные запуски не требуют UAC.
- EN/RU-сопряжение двух устройств и постоянная синхронизация через взаимный
  TLS. Интерфейс показывает фактическое применение, а не только отправку.
- Исправлен выбор окна за служебной точкой MWB: последнее рабочее окно получает
  общий язык без ожидания клика; фокус не перехватывается.
- Устранена устаревшая ошибка применения после успешного переключения.
- Устранён отказ при обратном порядке задач входа: обычный процесс запускает
  защищённый обработчик и ждёт готовности без нового запроса UAC.
- Добавлены установка/удаление/откат, проверка резервной версии до удаления,
  перезапуск через защищённые задачи и встроенная защита от заставки.
- Обычный build теперь собирает 1.1, а не прежнюю 1.0; PE timestamp отключён.

Стабильная 1.1.0 требует завершённой двухмашинной приёмки. RC не объявляет
непроверенные сон/блокировку, аппаратный LED или двухчасовой прогон успешными.

### Компоненты разработки, вошедшие в RC

- Разделены локальный повышенный движок и сетевые компоненты; добавлены
  защищённый локальный IPC, абсолютная установка EN/RU с проверкой результата,
  Schannel TLS и сопряжение с подтверждением второй стороны.
- Добавлены фильтрация доставленного ввода MWB, проверка поддерживаемой версии
  и безопасной конфигурации, ограниченная очередь событий и срок годности
  наблюдений. Ни исходные клавиши, ни текст, ни координаты не передаются.
- Подключено получение активности из движка через IPC; задержка обмена
  учитывается интервалом давности, без сравнения часов компьютеров.
- Аппаратный LED и чтение метаданных MWB выполняются вне hook/потока раскладки;
  зависание этих операций не должно удерживать переключение или остановку.
- Отдельный Screensaver Guard сохраняет запрет только заставки во время MWB,
  без синтетических движений, изменения сна, гашения экрана или автолока.
- Собирается единый EXE разработки: обычный фоновый broker, окно состояния и
  сопряжения, безопасный JSON-статус, экспорт диагностики и ротируемый журнал.
  Коды приглашения не включаются в статус, диагностику или журнал.
- Сопряжение и постоянная синхронизация используют один сетевой жизненный цикл;
  временный клиент до подтверждения не получает доступ к обмену раскладкой.
- Нативные задачи запуска имеют раздельные права и проверку владельца/ACL.
  Рабочая установка выполнена на ноутбуке и ПК.

Состояние и границы проверок:
[docs/1.1-status.md](docs/1.1-status.md).

## 1.0.0 — 2026-08-04

- Переключение English (US) ↔ Русский одиночным нажатием `CapsLock`.
- Обычный Caps Lock по `Shift+CapsLock` без смены языка.
- Индикация текущей раскладки светодиодом Scroll Lock.
- Быстрый keyboard hook на отдельном потоке и автоматическое восстановление
  после потери hook, сна, разблокировки и смены пользовательской сессии.
- Установка в профиль пользователя без UAC, скрытая фоновая работа и журнал
  только служебных событий.
- Сохранение прежней версии CapsLang в отключённом виде для безопасного отката.

### Ограничения

- EXE пока не подписан цифровым сертификатом, поэтому Windows SmartScreen может
  показать предупреждение.
- Из-за UIPI переключение не гарантируется в окнах, запущенных с повышенными
  правами.
